# 꼼지일기 (Kkomji Diary)

그리고, 말하고, 그림일기로. — 아이의 그림과 말을 하루 한 장 그림일기로 담고, 모아서 그림책으로 만드는 웹앱입니다.

서버와 빌드 과정 없이 동작하는 정적 사이트라서 GitHub Pages에 그대로 올릴 수 있습니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 소개 홈페이지 |
| `app.html` | 그림일기 앱 (PWA) |
| `js/app.js` | 앱 로직 전체 (저장, 그림판, 음성 인식, 그림책) |
| `css/app.css` | 앱 화면 스타일 |
| `css/book.css` | 그림책 인쇄 레이아웃 (216mm = 재단 210mm + 도련 3mm) |
| `ai/drawing-styles.json` | “꼼지가 그려줄게” 그림체 테마 4종 (서버 버전에서 사용) |
| `sw.js`, `manifest.webmanifest` | 홈 화면 추가 · 오프라인 열기 |

## GitHub Pages로 올리기

1. GitHub에서 새 저장소를 만듭니다. (예: `kkomji-diary`)
2. 이 폴더의 파일을 전부 저장소 최상위에 올립니다.
3. 저장소 **Settings → Pages → Build and deployment** 에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 고르고 저장합니다.
4. 1–2분 뒤 `https://<아이디>.github.io/<저장소 이름>/` 에서 열립니다.

음성 인식과 카메라는 `https` 주소에서만 동작합니다. GitHub Pages는 기본이 https입니다.

## 내 컴퓨터에서 열어 보기

```
python3 -m http.server 8000
```

실행 후 `http://localhost:8000` 을 엽니다. (`index.html`을 더블클릭해서 여는 방식은 저장 기능이 제한될 수 있습니다.)

## 지금 되는 것

- 그림판 (크레용 · 색연필 · 사인펜 · 지우개, 되돌리기, 자동 저장)
- 종이 그림 촬영 · 업로드, 회전 · 밝기 · 대비 보정 (원본 별도 보관)
- 말로 쓰기 (브라우저 음성 인식, 한국어 · 영어), 타이핑, 손글씨
- 날짜 · 날씨 · 기분 · 제목, 부모님 코멘트 (부모님 확인 후)
- 달력형 · 갤러리형 일기장
- 그림책 만들기: 기간 · 일기 선택, 표지 5종, 내지 5종, 펼침면 미리보기, 인쇄용 PDF
- 출석률과 완주 할인 대상 표시
- 한국어 · 영어 화면, 백업 파일 내려받기 · 불러오기

## 아직 안 되는 것 (서버가 필요한 기능)

- 회원 가입, 기기 간 동기화 — 지금은 일기가 **그 기기의 브라우저에만** 저장됩니다.
- AI 글 다듬기 · 번역 · AI 그림 꾸미기
- 종이 테두리 자동 인식 (문서 스캔)
- 결제, 실물 책 주문

음성 인식은 브라우저 기능을 쓰므로 Chrome, Edge, Safari에서 동작하고 Firefox에서는 타이핑으로 대신합니다.
